# Task-packet quality task

Status: used. Implementation tasks are task packets naming files, interfaces and the definition of done; scope is graded by `diff_scope` (allow, frozen tests); clarifications are counted.

Give the model a bounded handoff with explicit files, constraints, and a
definition of done.

Score first-pass completion, clarification count, scope adherence, invented
work, evidence quality, and whether the final report is usable by the next
agent.
