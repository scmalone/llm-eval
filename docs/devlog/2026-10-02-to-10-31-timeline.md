# Timeline, 2026-10-02 to 10-31 (backfilled)

Built from the 159 commits under `experiments/llm-eval` (`git log --reverse -- experiments/llm-eval`), the plans
and `DECISIONS.md`. It is the skeleton: the back and forth behind each step is in the archived transcripts
(`index.md` lists them). Numbers from before 2026-10-31 on engine 0.1.54 are a pre-fix record, not results.

## 1. A recall runner (Oct 2-3)

- A recoverable runner with a read-only preflight, recall haystacks sized to each context, smoke and vision trials,
  and a manifest of every preset profile.
- First review and red-team rounds (LLE-001..007, RT-001..004): the scratch server became a transient user unit,
  and the memory obligation survives cleanup and resume.
- First live acceptance runs. The first failed because 768 and 64-token output caps were spent on reasoning,
  which led to a 16K agent-turn output budget with truncation reporting and a smoke fail-fast.
- An HTML report per run and a `RUNS.md` ledger.

## 2. The workload benchmark (Oct 3-4)

- Plan accepted: real agent work through opencode in 7 categories taken from the owner's own logs, gated by
  code checks, with an offline judge.
- 35 tasks from real work, each proven to fail on a no-op and pass when solved; depth tasks via prelude turns;
  synthetic chat sweeps; simulated machine shims for ops tasks; a canned-page proxy.
- Blind review (WLR-001..009): grading moved inside the box, symlink-safe reveal of hidden tests, stricter gates.
- Wide raw capture (turns, end state, commands, host telemetry, server snapshots), from the owner's rule to
  capture widely because runs cannot be replayed.
- GPU-client detection changed from process name to VRAM use.
- The screen-then-top-3 plan, with efficiency red-team findings EF-001..009 and live-path RT2-001..010. Graders
  for advisory and review were tightened (EF-003); the scaled depth task fills to 90% of the compaction point.

## 3. Fixtures, scoring and Strata (Oct 5-17)

- Fixtures made standalone (a git bundle) with a privacy repair; equal-task scoring with conservative campaign
  uncertainty; a scoring red-team.
- Strata registered as a system under test (Oct 6). The benchmark's in-sandbox endpoint moved off 8080 to 8390.
- Rung 0, the pre-pilot gate (grading isolation, output caps).
- A systemd sleep lock for the campaign, after three red-teams (Oct 11).

## 4. The Strata adapter and engine 0.1.54 (Oct 28-30)

- Strata adapter spec; captured request contracts verified through real opencode; resumable paired campaigns.
- A VRAM gate failure led to a measured GPU ledger and a PCIe probe (the 6.8 GB/s reading was a cold Gen1 link).
- The 0.1.45 line archived; a fresh start on 0.1.54 with 131K and 262K as two arms of one comparison.
- Cohort runs: 12/18 at 131K and 12/18 at 262K.
- pi added as a second harness and then made the default: the owner's own pi, model entries and AGENTS.md.
- A depth suite, with a tool call at about 200K.
- An independent review corrected three claims; the vision task was dropped ("a documented fact, not a
  measurement").
- The unattended test plan and runner: fail closed, signal drills, `plan_ctl` launching a user unit under one
  sleep lock, a token-free watcher, and a run card for the administering agent.

## 5. Pre-run tuning (Oct 31)

- A speed sweep tuned the presets upward while memory was left; context and KV changes went to the owner as
  proposals. `qwen3.8-27b-unsloth-q4-mtp` at 163,840 was accepted.
- Request timeout scaled to context (a cold full-context prefill sends nothing for minutes); 1 s GPU telemetry.
- A defect: 262K llama.cpp presets could not run at 262K and silently fell back to their anchor (occamy-1.0 ran
  at 98,304). Fixed so a preset's own `ctx-size` is a rung.
- Plan scope: like for like at 131K, then dropped (owner); Qwen 3.8 UD-IQ4_XS added at 262K; gemma-4-31b-it out.
